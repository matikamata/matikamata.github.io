## 🌸 Missão

Preservar e distribuir os ensinamentos originalmente publicados em [PureDhamma.net](https://puredhamma.net) com um pipeline totalmente reproduzível — em Português, e futuramente em outros idiomas.

> *"Sua herança não está no banco."*

---

## 🏛️ Ecossistema AXIS-NIDDHI

```
axis-cli  ────────────────────────────────────────────────
  │   Unified CLI cockpit — orquestra todo o ecossistema
  │
  ├── axis-niddhi        Engine principal de preservação e publicação
  │     └── axis-niddhi-archive   Arquivo offline v3.0.2 (private)
  │
  ├── axis-nana          Knowledge engine — busca e citação canônica
  │
  ├── axis-navigator     Grafo semântico + trilhas de aprendizado
  │
  ├── axis-cosmos        Lab de arqueologia — dados derivados / não-canônicos
  │
  ├── axis-mirror        Sync multi-plataforma — Sojourner, Steward & IPFS
  │
  └── axis-preservation  Selos criptográficos + verificação de integridade
```

## 🏗️ Princípios Arquiteturais

| Princípio | Descrição |
|---|---|
| **Determinismo** | Mesmo input → mesmo output, sempre |
| **Reprodutibilidade** | Rebuild completo a partir do backup original |
| **Offline-first** | Funciona sem internet — IPFS + arquivos locais |
| **Auditabilidade** | Todo passo é rastreável por humanos |
| **Preservação de longo prazo** | Arquival estável para gerações futuras |
